# Tower of Hanoi Solver

A Python implementation of the classic mathematical puzzle **Tower of Hanoi**. Utilizes recursion to determine optimal moves and records the full visual state of all three rods (`A`, `B`, `C`) after each step. Built for the **freeCodeCamp Scientific Computing with Python** certification.

## 🛠️ Features

* **Recursive Algorithm:** Implements an optimal $O(2^n - 1)$ recursive solution to solve the puzzle for $N$ disks.
* **State Tracking:** Records and logs the exact distribution of disks across all rods at every step.
* **Dynamic Data Structures:** Uses dictionaries and lists to represent rods and disk stacks.

## 💻 Tech Stack

* **Language:** Python 3 (Recursion & Data Structures)
